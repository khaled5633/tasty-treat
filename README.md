# TastyTreat — assessment preparation (Step 1)

This is your original dessert website, *not* a new replacement design. Open `index.html` or serve this folder with `python3 -m http.server 8000`.

Read `docs/START_HERE_STEP_BY_STEP.md` first, followed by `docs/AWS_EC2_GUIDE.md` for your practical deployment.

**Important:** This static site does not process payments, send enquiries, run a backend or automatically meet the Operating Systems & Cloud assessment. Its appropriate role is as a simple application to deploy to a VM; the ABC Exclusive analysis and AWS/Apporto evidence must be added separately.

Run `python3 tests/test_site.py` to check the website file references and structure.
